# Dini Asistan — Kur'an

Mobil uyumlu, sade Kur'an okuma uygulaması.

## İlk sürüm

- 114 sure listesi
- Sure adına veya numarasına göre arama
- Arapça Kur'an metni
- Uygun Türkçe meal sürümünü otomatik seçme
- Son okunan sureyi hatırlama
- PWA desteği ve temel çevrimdışı önbellek

## Veri kaynağı

Kur'an verileri Al Quran Cloud REST API üzerinden yüklenir:
https://api.alquran.cloud/v1
